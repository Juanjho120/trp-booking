## 12.5.1 Accepted Correction

Real provider data showed that Airbnb exported both:

```text
SUMMARY: Reserved
SUMMARY: Airbnb (Not available)
```

The Phase 7 assumption that every active VEVENT represented a booking was incorrect for real provider data.

12.5.1 corrected the import contract:

```text
Reserved
-> source-property AIRBNB block
-> configured TRP preparation buffers

Airbnb (Not available) / unknown active summary
-> source-property AIRBNB block
-> no additional TRP preparation buffers
```

The importer also stopped physically propagating provider blocks across the composed listing. The availability service remains the single place that derives which other accommodations are blocked.

Implementation commit:

```text
438f3b95afecdfed5e4fd2df0b3a89856f276dbd
```
